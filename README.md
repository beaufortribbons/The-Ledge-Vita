# The Ledge — PS Vita homebrew port

A short narrative game originally made with RPG Maker MV, now adapted for
homebrew-enabled PS Vita systems. Approximate play time: five-ten minutes.

Created by James Beaufort @ http://beaufort.asia. 

Based on the short story 'Man With A Problem' by Donald Honig (1958).

**Content warning: suicide, death and disturbing imagery.**

## Download and install

Download **The-Ledge-Vita-0.34.vpk**, transfer it to your Vita, and install it
using VitaShell. Movies and audio are included; no separate data download is
needed. When updating, keep your existing installation and saves. Save data
is stored in `ux0:data/TheLedge/`.

The **Sources.zip** download contains the program source and build materials;
players do not need it. Read the attached **CREDITS.txt** and **README.txt**.

## Controls

- D-pad / left stick: move.
- Cross: confirm / interact. Circle: cancel (subject to system remapping).
- START / Triangle: pause, save, load or return to the title.

## This release

Public credits, documentation and third-party notices have been added or
updated. Gameplay, graphics, movie/audio data, native executable and save
format are unchanged from v0.33.

Minor slowdown can remain in the house scene involving the wife's body.
